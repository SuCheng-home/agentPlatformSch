## 开关与文件

- `.env.dev_test` 的 `VITE_USE_MOCK=true` 启用本地数据；`VITE_SKIP_LOGIN=true` 跳过本地登录。
- `src/utils/api-request.js` 在 HTTP 发送前分流。各 API 文件原 URL、参数、方法和真实调用全部保留，未知模拟路径报出未接入，绝不回退线上。
- `snapshot.json` 保存原始展示数据、学科和教材章节；`mock-assets/` 保存本地图片，由 Vite 开发服务作为静态文件提供，生产构建不包含这些演示图片。
- `request-handler.js` 处理分页和本地操作；浏览器存储键为 `agent-platform-sch-local-demo-v1`，删除此键后刷新可重置演示。
- `scripts/capture-preview-snapshot.py` 可手动重新采集公开快照，需要 Python 和 Pillow。采集会访问线上，只读获取列表、字典和图片，不调用计数更新、使用记录或其他写接口；日常页面展示不会运行采集脚本。
